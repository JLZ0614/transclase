隐私政策

最后更新：2026 年 11 月 16 日 · 适用于 macOS 版 Transclase（1.6.0 起）

一句话总结

Transclase 不要求注册，不收集账号，不做统计分析，不投放广告。 课堂音频只在本机内存中处理，不会上传；逐字稿和要点保存在你自己的电脑上。 只有当你主动开启「云端 API」或「AI 助手」时，识别出的文字才会发送到你自己配置的服务商。

1. 我们处理哪些数据

1.1 音频

麦克风采集的音频通过 Apple 的端上语音识别框架实时转成文字。 音频在内存中处理后立即丢弃，不写入磁盘，不上传，任何情况下都不会被保存或回放。

1.2 文字内容

逐字稿、译文和 AI 要点保存在本机 App 沙盒内的 Markdown 文件中 （~/Library/Containers/com.transclase.app/…/Transclase/Sessions）。 这些文件只有你和本 App 能读取；你可以随时在访达中查看、编辑或删除。 卸载 App 时，这些文件会一并删除。

1.3 API 密钥

你填入的服务商 API Key 保存在 macOS 钥匙串（Keychain）中， 用于向该服务商发起请求，不会被发送给开发者，也不会被写入日志。

1.4 我们不收集

不收集姓名、邮箱、手机号、位置、通讯录、设备标识符； 不使用任何第三方统计、崩溃上报或广告 SDK；不进行跨 App 追踪。

2. 什么时候数据会离开你的设备

只有在你主动把翻译引擎切换为「云端 API」，或在 AI 助手中提问时， 识别出的文字才会通过 HTTPS 发送到你在设置里填写的服务商 （例如 DeepSeek，或你自建的中转服务）。

发送的内容包括：待翻译的句子、少量上下文、以及你的提问。 音频本身不会发送。 这些数据在该服务商处的处理方式，适用其自身的隐私政策，我们无法控制。 如果你不希望任何文字离开本机，请在设置中选择「系统离线翻译」并不要使用 AI 助手。

3. 数据保留与删除

  • 逐字稿与要点：保留在你的电脑上，直到你删除对应文件或卸载 App。
  • API Key：保留在钥匙串中，直到你在设置里清空或卸载 App。
  • 开发者侧：我们不运营服务器，因此不持有你的任何数据。

4. 麦克风与录音合规

Transclase 只做实时转写，不保存录音文件。 但在课堂上录音或记录他人发言，可能受到你所在学校的规定以及当地法律的约束。 请在开始前自行确认并获得必要许可，相关责任由使用者承担。

5. 儿童隐私

本 App 不面向 13 岁以下儿童单独提供服务，也不会有意收集儿童的个人信息。

6. 政策变更

如果数据处理方式发生实质变化（例如接入由开发者运营的中转服务）， 我们会更新本页面并修改上方的「最后更新」日期。重大变更会在 App 内提示。

7. 联系方式

与隐私相关的问题，请通过 GitHub Issues 或邮件 privacy@example.com 联系开发者。
