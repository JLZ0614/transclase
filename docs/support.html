安装

推荐用一行命令，会自动放入「应用程序」并去掉隔离标记：

curl -fsSL https://raw.githubusercontent.com/JLZ0614/transclase/main/scripts/install.sh | bash

或使用 Homebrew：

brew install --cask JLZ0614/transclase/transclase

常见故障

提示「无法验证开发者」或「已损坏」

App 未经过 Apple 公证。右键打开在 macOS 15 之后已经失效，请到 「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。 或者直接用上面的 curl 命令安装，脚本会清除隔离标记。

首次打开要下载几百 MB

Apple 的语音识别模型和翻译语言包是按需下载的，不是系统预装。 在首页点击「开始听课」后会提示下载，完成后上课全程离线。

翻译没有出现，只显示原文

说明离线语言包还没装好。到「设置 → 翻译」点「下载 / 刷新离线语言包」， 在系统面板里确认下载完成。也可以在设置里改用「云端 API」。

云端翻译或 AI 助手报错

检查三件事：地址是否以 /v1 结尾、模型名是否和你的服务商一致、 API Key 是否有效。设置里有「测试连接」按钮，会真的翻一句并显示耗时。

AI 助手说「没有可总结的内容」

助手只总结已经识别出的字幕。请先开始一节课并让它跑一小段，再点「总结」。

录音没有反应

到「系统设置 → 隐私与安全性 → 麦克风」确认 Transclase 已勾选； 同时检查输入设备是否选对（外接麦克风/耳机）。

换了电脑，以前的课程记录还在吗

课程记录保存在本机 App 沙盒里，不随账号同步。卸载 App 会一并删除， 建议定期用「导出」功能保存 Markdown。

反馈问题时请附上

  • macOS 版本（关于本机 → 版本号）
  • 芯片型号（Apple Silicon / Intel）
  • 设置里显示的翻译引擎与「测试连接」的结果
  • 出问题时的截图（不要包含密钥）
